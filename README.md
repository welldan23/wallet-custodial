# MyWallet Stablecoin

Wallet kripto **non-custodial** untuk pengguna Indonesia yang pegang stablecoin
(USDC, USDT) di Ethereum, Arbitrum, Base, Polygon, dan Solana. Kunci privat &
12 kata pemulihan cuma disimpan di HP pengguna.

| Folder | Isi |
| --- | --- |
| [`mobile/`](mobile/) | Aplikasi iOS & Android (Expo + React Native) |
| [`backend/`](backend/) | API data publik: jaringan, token, harga, ringkasan saldo (Hono + SQLite) |

Cara menjalankan ada di [`mobile/README.md`](mobile/README.md) dan
[`backend/README.md`](backend/README.md).
